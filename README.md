# Little Apps · Browser edition

Small, quiet games and tools for e-ink readers. Open the website in the Kindle
Web Browser and bookmark it. No jailbreak, account or computer server is needed.

Includes TicTacToe, Sudoku, Maths, Match, Words, Draw, Sticky and Notes, plus clock
and calendar widgets. Built with HTML, CSS, JavaScript and locally hosted fonts.

## Using a regular Kindle

Open the Kindle menu → Web Browser (or Experimental Browser), enter the website
address, and bookmark it. Keep JavaScript enabled. Use the browser's normal exit
controls to return to Kindle Home. Browser bars stay under the Kindle's control.
Older models/firmware may differ; this edition needs testing on your device.

The fullscreen button appears in the upper right when the browser reports
fullscreen support. Opening another app may leave fullscreen. Use that app's
fullscreen button to enter it again.

## Your work

Drawings, notes and settings save in browser storage on that device and website
address. They do not sync or upload to this repository. Clearing browser data
removes them. An internet connection is required to load the site.

The calendar is a local month view, with no personal calendar integration.
Native Kindle status-bar controls, Home-screen installation and the temporary
drawing-share server are not part of this static browser edition.
